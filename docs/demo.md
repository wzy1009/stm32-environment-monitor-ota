# 比赛演示清单

这是一份待实板执行的流程，不是已完成的实测记录。建议录一段连续视频，按下面顺序演示。

| 步骤 | 操作 | 应观察到 |
|---|---|---|
| 1 | 上电 | 显示固件版本、温湿度和 PIR 预热；默认撤防 |
| 2 | 等待预热结束，按 KEY0 布防，等待 3 秒后走动 | 蜂鸣器间歇响、报警保持，OLED 显示活动和报警 |
| 3 | 按 KEY1 | 立即撤防并清报警；双键同按也以撤防优先 |
| 4 | 查看巴法云 `envState` | 温湿度、布防、活动、报警次数和版本定时更新 |
| 5 | 云端发送 `ARM`、`DISARM`、`STATUS` | 板端状态随命令变化；按住 KEY1 时远程布防无效 |
| 6 | 断网后恢复 | 本地采集和按键仍工作；恢复联网后上报最新状态 |
| 7 | 撤防，下发已核对的新版本 OTA JSON | OLED 显示下载、校验、安装；重启后显示新版本 |
| 8 | 查看云端 | `version` 变为新版本，监测和远程控制恢复 |

准备两份版本不同、与联网配置一致的 APP BIN。初始版本用联合 HEX 烧录，新版本只作为 OTA BIN 下发；下载 URL、大小和 MD5 都由实际文件生成，见 [OTA 说明](ota.md)。

再做故障演示：错误 MD5 时不提交安装；下载中断后恢复网络重发；按住 KEY1 时禁止布防；断开 DHT11 时显示采集错误，云端温湿度为 `null`。同版本通知应被忽略。

实板记录填写：日期、固件版本与 MD5、ESP8266 AT 版本、实际现象、照片或连续视频、未解决问题。真实安装断电测试需单独准备恢复手段，不能用模拟测试结果代替实测。
