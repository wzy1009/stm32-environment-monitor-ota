# 硬件与引脚

依据：此前提供的《STM32F1战神V1_原理图V3.0》及现有 OTA 工程配置。

| 功能 | 引脚/接口 | 本阶段 |
|---|---|---|
| LED0 | PB5，低电平亮 | 已配置，500 ms 翻转 |
| LED1 | PE5，低电平亮 | OLED 错误提示 |
| OLED SCL | PD9 | 已配置，软件 I²C |
| OLED SDA | PE15 | 已配置，软件 I²C |
| OLED 电源 | 3.3 V / GND，模块需有上拉 | 沿用现有接线 |
| SWD | PA13 / PA14 | 用于调试下载 |
| USART1 | PA9 TX / PA10 RX | 现有串口下载接口，本阶段无串口业务 |
| ESP8266 | USART3，PB10 TX / PB11 RX | 后续接入 |
| SPI Flash | PB12 CS、PB13 SCK、PB14 MISO、PB15 MOSI | 后续 OTA 使用 |
| AT24C02 | PB6 SCL、PB7 SDA | 后续 OTA 使用 |
| DHT11 | 板载 P13 接口，数据引脚待逐网核对 | 尚未接入 |
| SR602 | 外接 GPIO 待确定 | 尚未接入 |
| 蜂鸣器 | 原理图 V3.0 为 3.3 V 有源，控制引脚待核对 | 尚未接入 |

SR602 用于人体活动触发，不能据此可靠判断静止人员是否仍在。板载 HS0038 是遥控红外接收器，不能替代 SR602。
