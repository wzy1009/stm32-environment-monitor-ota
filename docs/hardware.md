# 硬件与引脚

战神 STM32F1 V1，STM32F103ZET6。依据《STM32F1战神V1_原理图V3.0》第 3、4 页核对。

| 功能 | 引脚/接口 | 说明 |
|---|---|---|
| DHT11 DATA | PG11 / P13-2 | P13-1 为 3.3 V、P13-3 为 NC、P13-4 为 GND；R40 为 4.7 kΩ 上拉 |
| SR602 OUT | PG10 / P10-22 | 扩展输入，内部下拉，输入应为 3.3 V 逻辑 |
| SR602 电源 | 与开发板共地 | 确认模块支持 3.3 V 供电后再接板上 3.3 V，引脚按模块标识连接 |
| KEY0 | PE4 | 按下为低，30 ms 消抖，切换布防/撤防 |
| KEY1 | PE3 | 按下为低，优先撤防；双键同按也保持撤防 |
| 板载蜂鸣器 | PB8 | 高电平响，Q3/S8050 驱动；V3.0 为 3.3 V 有源蜂鸣器 |
| LED0 / LED1 | PB5 / PE5 | 低电平亮；本固件按 LED0 红、LED1 绿配置：未检测到活动亮绿灯，检测到活动亮红灯。原理图未标灯珠颜色，需以实板确认 |
| OLED SCL / SDA | PD9 / PE15 | P1-20 / P1-18，软件 I²C，需有上拉 |
| OLED VCC / GND | P1-24 / P1-22 | 3.3 V / GND |
| SWD | PA13 / PA14 | 调试下载 |
| USART1 | PA9 TX / PA10 RX | 115200、8N1，下载进度与故障日志；协议使用 USART3 |
| ESP8266 | USART3，PB10 TX / PB11 RX | 115200、8N1；接板载 P2 时，P7 跳线接 3–5、4–6 |
| SPI Flash | PB12 CS、PB13 SCK、PB14 MISO、PB15 MOSI | SPI2，暂存升级 BIN；16 MiB 器件 |
| AT24C02 | PB6 SCL、PB7 SDA | I²C1，保存升级记录与提交标志 |

P13 是四脚 DHT11/DS18B20 共用接口。三脚 DHT11 模块按 VCC、DATA、GND 接线，不按位置直接插入；不要同时连接 DS18B20。

PG10 是本项目选用的扩展输入，确认该位置没有连接其他模块。板载 HS0038 是遥控接收器，不能替代 SR602，不要将 SR602 与其 PB9 输出并接。

引脚配置集中在 `firmware/Core/Src/board_io.c`。以上是原理图和代码配置核对结果，实物板版本与接线仍待确认。

ESP8266 需使用兼容 `AT+CWMODE_CUR`、`AT+CWJAP_CUR`、`AT+CIPSTART` 的 AT 固件，工作在单连接、非透传、主动 `+IPD` 接收模式。连接外置模块时 TX/RX 交叉并共地；使用 3.3 V 逻辑和供电稳定的模块电源。
